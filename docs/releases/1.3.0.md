## English

- **Browsers:** Vacuo now finds the caches of your browsers and clears the ones you pick.
- **File types:** The disk map now shows which types of file take up the space.
- **Crash log:** If Vacuo stops on an error, it now writes down what happened.

## Türkçe

- **Tarayıcılar:** Vacuo artık tarayıcılarının önbelleklerini buluyor ve seçtiklerini temizliyor.
- **Dosya türleri:** Disk haritası artık alanı hangi dosya türlerinin kapladığını gösteriyor.
- **Hata kaydı:** Vacuo bir hatayla kapanırsa artık ne olduğunu kaydediyor.
