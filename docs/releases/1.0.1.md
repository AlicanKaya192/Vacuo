## English

- Updates keep working after the repository was renamed to **Vacuo**: the update check now accepts the repository's address in any letter case. Vacuo 1.0.0 cannot update itself because of this; if you have it, download this version once from this page.
- Links to the project, its issues and its releases point to the new address.
